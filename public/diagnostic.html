⚠️ Common Issues & Solutions

❌ File protocol detected (file:///)

→ Don't open HTML file directly! Start server and use http://localhost:3000/diagnostic.html

❌ Server not running

→ Open terminal and run: npm install then npm start

❌ Wrong port

→ Make sure server.js uses port 3000 and you're accessing localhost:3000

❌ Socket.io not loading

→ Check browser console (F12) for 404 errors on /socket.io/socket.io.js
